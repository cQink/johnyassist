# Один браузер и предсказуемые вкладки

Дата: 2026-07-27

## Что сломано

Живая проверка цепочек вскрыла три связанные проблемы. Все три — про одно: Джони не управляет тем браузером, который человек видит.

### 1. Браузер-зомби

Замер во время сессии: порт 9222 отвечает, целей семь — **и ни одной страницы**. Все семь это фоновые страницы и service worker'ы расширений.

Процесс Chrome-Джони жив (его держат расширения), окон у него нет. `_port_open()` честно отвечает «порт открыт, запускать нечего», и `driver.get(url)` создаёт страницу в браузере без окна. Отсюда «видео открывается непонятно где»: страница есть, показать её негде.

### 2. Драйвер никогда не перенацеливается

В `browser.py` нет ни одного `switch_to.window`. Драйвер цепляется к произвольной вкладке при первом обращении, кешируется в глобальной `_driver` и работает с ней всегда. `bring_to_front` поднимает окно, но активной в нём остаётся та вкладка, которую смотрит человек, — Джони же работает в другой.

Поэтому цепочка «найди → включи первое видео → на полный экран» способна отработать в трёх разных местах, а фуллскрин честно рапортует «не нашёл плеер на странице»: на *его* странице плеера действительно нет.

### 3. Два браузера

Отдельный профиль появился вынужденно: с Chrome 136 отладочный порт запрещён на профиле по умолчанию (проверено на Chrome 150 — ограничение в силе). Обойти нельзя, управлять основным Chrome невозможно в принципе.

Но человек пользуется обоими: закреплённый на панели задач Chrome — основной, ссылки из Discord открываются в нём, и Джони до них не дотягивается.

**Переносить данные не придётся.** Замер профилей: одинаковый размер базы паролей (40 КБ) и ровно по 17 расширений в обоих — синхронизация Google уже всё перенесла. Закладок нет ни в одном. Отличается только локальная история.

## Решения

| Вопрос | Решение |
|---|---|
| Куда открывать | Каждый раз **новая вкладка** |
| Как открыть в текущей | Модификатор фразы «в этой вкладке» |
| Ссылки из других программ | Регистрируем «Chrome (Джони)» как браузер Windows |
| Перенос профиля | Не нужен, синхронизация уже сработала |

## Часть 1. Вкладка Джони

Вводится понятие текущей вкладки Джони:

```python
_tab = None   # handle вкладки, в которой Джони работает сейчас
```

**Открытие** (`browser.open(url, new_tab=True)`): `switch_to.new_window("tab")`, запомнить handle в `_tab`, загрузить URL, поднять окно.

**Остальные действия** (`click_result`, `seek`, `seek_relative`, `next_video`, `fullscreen`): перед работой переключиться на `_tab`. Сейчас этого нет вообще — в этом корень бага с фуллскрином в цепочке.

**Вкладки Джони больше нет** (человек закрыл): работаем с текущей активной вкладкой. Так интуитивнее — сказал «на полный экран», глядя на видео, развернётся видимое.

**Страниц нет совсем** (зомби): открываем **окно**, а не вкладку — `switch_to.new_window("window")`. Если и это не удалось (драйвер не смог прицепиться к браузеру без страниц), запускаем `chrome.exe` с тем же `--user-data-dir`: работающий процесс на это открывает новое окно.

Единая точка входа — `_focus_tab()`, её зовут все действия. Дублировать переключение по функциям нельзя, копии разъедутся.

## Часть 2. Модификатор «в этой вкладке»

Писать в `commands.yaml` пары «команда» / «команда в этой вкладке» пришлось бы к каждой из полусотни сайтовых команд: сто строк и обязанность дописывать вторую половину при каждой новой команде. Поэтому — модификатор фразы, а не команды.

Чистая функция в `johnny/browser_target.py`:

```python
strip_tab_modifier(text: str) -> tuple[str, bool]
```

Возвращает пару `(фраза_без_хвоста, new_tab)`. Хвост найден → `new_tab=False` (работаем в текущей вкладке); хвоста нет → фраза возвращается как есть и `new_tab=True`. Хвосты: «в этой вкладке», «в текущей вкладке», «в этом окне».

`handle_command` вызывает её **до** лестницы разбора, поэтому модификатор работает со всеми командами сразу, включая будущие, и внутри цепочек тоже: «найди на ютубе X в этой вкладке и включи первое видео».

Флаг доходит до `browser.open` параметром `new_tab`, через `actions.execute(..., new_tab=True)` и `chain.run(..., new_tab=True)`.

Границы, выбранные осознанно:
- Если после отрезания хвоста не осталось ничего (сказано просто «в этой вкладке») — не отрезаем, пусть фраза идёт в модель как обычная.
- Модификатор действует на **всю фразу**, а не на отдельный шаг цепочки. Разделение по шагам — сложность без спроса.

## Часть 3. Один браузер на всё

Скрипт `install_browser.py` по образцу существующего `install_autostart.py`, с ключом `--uninstall`:

1. **Регистрирует приложение** «Chrome (Джони)» в реестре пользователя (`HKCU\Software\Clients\StartMenuInternet`, ProgID с `shell\open\command`, запись в `RegisteredApplications`) с командой запуска:
   ```
   chrome.exe --user-data-dir="D:\assistent\chrome-profile"
              --remote-debugging-port=9222 -- "%1"
   ```
2. **Кладёт ярлык** «Chrome (Джони)» на рабочий стол — его человек закрепит на панели задач вместо нынешнего.
3. **Печатает путь по экранам** настроек, где надо один раз выбрать приложение для HTTP и HTTPS.

Выбрать ассоциацию программно нельзя: Windows защищает UserChoice хешем. Это единственный ручной шаг, он занимает две минуты и полностью обратим через `--uninstall`.

Профиль и порт берутся из тех же значений, что использует `browser.py` (`_PROFILE`, `_PORT`), а не дублируются строкой — иначе при смене порта регистрация тихо разъедется с кодом.

### Риск, принятый осознанно

Отладочный порт на повседневном браузере — это доступ к залогиненным сессиям для **любой программы на этом компьютере**. Порт слушает только localhost, снаружи не достучаться. Сегодня под этим риском уже находится профиль Джони с Google-аккаунтом; после перехода там окажется вся обычная работа в вебе. Пользователь предупреждён и выбрал этот вариант.

## Тестирование

**Вкладки** — поддельный драйвер с `window_handles`, `switch_to.new_window` и записью переключений:
- открытие создаёт новую вкладку и запоминает её handle;
- действие переключается на вкладку Джони перед работой;
- закрытая вкладка Джони роняет на текущую активную, а не в исключение;
- пустой список вкладок даёт **окно**, а не вкладку;
- `new_tab=False` не создаёт вкладку, а работает в текущей.

**Модификатор** — чистая функция:
- три формулировки хвоста отрезаются;
- фраза без хвоста не меняется;
- фраза из одного хвоста остаётся целой (не превращается в пустую).

**Регистрация** — проверяется только сборка строки запуска: в ней правильный профиль и правильный порт, взятые из `browser.py`. Реестр в тестах не трогаем; успех записи проверяется тем, что приложение видно в настройках Windows.

**Живая проверка** (человек): сказать «найди на ютубе Exile Show и включи первое видео на полный экран» и увидеть, что всё произошло в одной новой видимой вкладке, куда Джони переключил.

## Вне рамок

- Управление основным Chrome — невозможно, ограничение Chrome 136+.
- Расширение для браузера — отвергнуто в проекте раньше.
- Автоматическая простановка браузера по умолчанию — запрещено Windows.
- Закрытие накопившихся вкладок Джони.
