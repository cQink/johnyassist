# Итерация «Браузерное управление» — дизайн

**Дата:** 2026-07-25
**Статус:** согласован

## Цель
Голосом управлять содержимым YouTube (и позже Spotify): включить N-й результат
поиска, перемотать на точное время, следующее видео, полный экран, пауза.

## Ключевое решение
Джони держит **своё окно Chrome** — отдельный профиль с включённой отладкой
(Chrome 136+ запрещает отладку на основном профиле, поэтому только так).
Управление страницей — через **Selenium** (attach по debug-порту, JS на странице).

- Профиль: `<root>/chrome-profile/` (gitignored).
- Запуск: `chrome.exe --user-data-dir=<профиль> --remote-debugging-port=9222`,
  лениво при первой браузерной команде; окно переиспользуется.
- Пользователь один раз логинится в этом окне (YouTube/Google). Может
  пользоваться им как обычным браузером. index.html/внешние ссылки — в основной
  Chrome (ограничение Windows UserChoice, решили простым путём).

## Модуль `johnny/browser.py`
- `get_driver()` — если порт 9222 не отвечает, запустить Chrome-Джони и
  подождать; затем attach Selenium (`debuggerAddress=127.0.0.1:9222`). Драйвер
  кэшируется. Selenium Manager сам подтянет chromedriver.
- `open(url)` — навигировать окно Джони на URL.
- `click_result(n)` — кликнуть N-й (1-based) видео-результат YouTube.
- `seek(seconds)` — `document.querySelector('video').currentTime = seconds`.
- `next_video()` — кнопка «Далее»/шорткат.
- `fullscreen()` — клавиша `f` по видео.
- `play_pause()` — `video.play()/pause()` (или медиа-клавиша).

## Разбор времени (чистая функция, тестируется)
`parse_time_ru(text) -> int|None`:
- «13 42» / «13 минут 42» → 822
- «5 минут» → 300, «30 секунд» → 30, «полторы минуты»? (нет, только числа)
- «1 03 05»? — v1: поддержать «мм сс» и «X минут[ Y секунд]».

## Действия (`actions.py`)
- `browser_open(url)` — открыть в окне Джони.
- `browser_click_result(n)`, `browser_seek(seconds)`, `browser_next`,
  `browser_fullscreen`, `browser_play_pause`.
Все — тонкие обёртки над `browser.py`; в тестах Selenium/driver мокаем.

## Команды v1
- Поиск/открытие → окно Джони: «найди X на ютубе», «включи X на ютубе»,
  «открой ютуб» (переключаем существующие open_url на browser_open).
- «включи первое/второе/третье видео» → click_result(1/2/3).
- «перемотай на 13 42», «перемотай на 5 минут», «на 30 секунд» → seek.
- «следующее видео» → next_video.
- «разверни на весь экран» / «на весь экран» → fullscreen.
- «пауза»/«продолжи» — оставляем медиа-клавиши (работают и так), а на странице
  play_pause как запасной вариант позже.

## Зависимости
`selenium` (Selenium Manager сам качает драйвер).

## Тесты
- `parse_time_ru` — таблица кейсов.
- Диспетч действий (browser.py мокается): click_result/seek/next вызываются с
  правильными аргументами.
- Реальная работа с YouTube — вживую на машине (attach, клик, seek).

## Вне v1
- Плейлисты Spotify по названию, сложная навигация Spotify.
- Перенос окна Джони на монитор в связке с браузерными командами.
- Монитор-комбо «включи X на ютубе на N мониторе» пока остаются на старом
  потоке (отдельное окно основного Chrome); унификация — позже.
