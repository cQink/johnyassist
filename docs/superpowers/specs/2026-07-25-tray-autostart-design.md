# Итерация «Всегда наготове» (трей + автозапуск) — дизайн

**Дата:** 2026-07-25
**Статус:** согласован

## Цель

Джони работает **без окна консоли**, висит **иконкой в трее**, стартует
**вместе с Windows**. Можно быстро поставить на **паузу** (чтобы во время
войсчата не ловил ложные «Джонни»). Логика команд не меняется — оборачиваем.

## Компоненты

### `AssistantController` (в `johnny/app.py` или новом `johnny/controller.py`)
Оборачивает цикл прослушивания с управлением:
- `pause()` / `resume()` / `paused` — временно игнорировать активатор (флаг `threading.Event`).
- `stop()` — завершить цикл.
- `last_command: str` — что распознали в прошлый раз (для меню трея).
- Цикл: ждём активатор → если пауза/стоп, пропускаем → `speaker.acknowledge()`
  → распознаём → `handle_command`. Recognizer/Listener создаются внутри
  (тяжёлые), в тестах инжектируются фейки.

### `johnny/autostart.py`
Ярлык `.lnk` в папке «Автозагрузка» (`%APPDATA%\...\Startup`):
- `shortcut_path() -> Path`
- `is_installed() -> bool`
- `install(pythonw, script, workdir) -> Path` (через WScript.Shell/pywin32)
- `uninstall() -> bool`
Тестируем логику пути/наличия/удаления (моком `%APPDATA%` → tmp); реальную
установку `.lnk` проверяем на живой машине.

### `johnny/tray.py`
- Иконка `pystray` + меню:
  - **⏸ Пауза / ▶ Слушать** (переключатель, меняет иконку)
  - **Последняя команда: …** (неактивный пункт-подпись)
  - **⚙ Автозапуск** (переключатель → `autostart.install/uninstall`)
  - **✖ Выход**
- Иконка меняет цвет: слушает (зелёная) / пауза (серая).
- Ассистент-цикл — в фоновом потоке (daemon); трей — на главном.

### Точка входа `johnny_tray.pyw`
Запуск без консоли (`pythonw`). Содержит только вызов `tray.main()`.

### Логирование
Раз нет консоли — в файл `johnny.log` (модуль `logging`), уровень INFO:
старт, распознанное, ошибки. `handle_command`/цикл пишут в лог.

## Зависимости
`pystray`, `Pillow` (иконка). Ставятся в venv. `.lnk` — через уже стоящий
`pywin32`.

## Автозапуск
Включаем сразу: скрипт `install_autostart.py` ставит ярлык на
`pythonw johnny_tray.pyw`. Выключение — тем же скриптом (`--uninstall`) или
пунктом меню.

## Пауза — зачем
Джони слушает всегда; во время игры/дискорда возможны ложные срабатывания.
Пауза глушит реакцию на активатор одним кликом; иконка показывает статус.

## Вне итерации
Умные каналы, мультимониторность, медиа-клавиши — отдельными итерациями.
Логика распознавания/команд не трогается.
