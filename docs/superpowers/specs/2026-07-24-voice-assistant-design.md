# Голосовой ассистент «Джони» — дизайн (v1)

**Дата:** 2026-07-24
**Статус:** согласован, готов к планированию реализации

## Цель

Голосовой ассистент в стиле «Джарвиса» для Windows: по слову-активатору
«Джони» слушает команду, распознаёт её и выполняет действие на ПК —
запуск игр/программ, открытие сайтов с поиском, системные команды, а также
свободные вопросы. Всё офлайн и бесплатно, кроме опционального «умного»
разбора через Claude Code на Pro-подписке.

## Принципы

- **Основа — шаблоны** (локально, мгновенно, бесплатно, без интернета).
- **Claude Code (`claude -p`) — запасной «умный» мозг** для свободных фраз;
  работает на Pro-подписке, без отдельного API-ключа и доплат.
- **Пользователь настраивает поведение через YAML**, не трогая код.
- **Ничего не запускается без явной команды** после слова-активатора.

## Поток работы

```
микрофон всегда слушает слово-активатор «Джони»
   │  (Porcupine — точно, быстро, почти не грузит ПК)
   ▼
услышал «Джони» → короткий сигнал «слушаю»
   │
   ▼
записывает фразу до паузы → Whisper (на RTX 3070) распознаёт текст
   │
   ▼
Роутер: подходит ли шаблон из commands.yaml?
   ├─ ДА  → выполняет действие (launch_app / open_url / system)
   └─ НЕТ → отправляет фразу в `claude -p` → тот решает действие/ответ
   │
   ▼
Speaker: отвечает голосом / сигналом / молча (по настройке)
```

## Компоненты

Каждый — отдельный модуль с одной задачей и понятным интерфейсом.

| Модуль | Задача | Технология |
|--------|--------|-----------|
| **Listener** | Ловит слово-активатор «Джони» | Picovoice Porcupine (офлайн, кастомное слово) |
| **Recognizer** | Распознаёт саму команду в текст | faster-whisper на GPU (CUDA) |
| **Router** | Сопоставляет текст с шаблонами; иначе → ClaudeBrain | свой парсер + `commands.yaml` |
| **Actions** | Выполняет действия | subprocess / webbrowser / pycaw |
| **ClaudeBrain** | Запасной умный разбор свободной речи | вызов `claude -p`, парсинг ответа |
| **Speaker** | Голосовой/звуковой отклик | Silero TTS (офлайн), сменный; режимы voice/beep/off |
| **Config** | Игры, сайты, шаблоны, настройки | YAML-файлы |
| **Orchestrator** | Главный цикл, связывает всё | main-модуль |

### Слово-активатор (Porcupine)

- Слово: **«Джони»** (создаётся текстом в консоли Picovoice, голос не
  записывается; скачивается `.ppn`-модель, работает офлайн).
- Нужен бесплатный аккаунт Picovoice и access key (кладётся в настройки).
- Русская модель Porcupine. Если качество «Джони» окажется недостаточным
  на этапе тестирования — подбираем созвучное слово, удобное движку.

### Распознавание команды (Whisper)

- `faster-whisper` на GPU (RTX 3070, CUDA) — быстро и точно для русского.
- Запускается только ПОСЛЕ слова-активатора (не гоняет весь звук постоянно).
- Запись команды — до паузы (детект тишины).

### Мозг: шаблоны + Claude

- **Шаблоны** (`commands.yaml`): `*` — подстановка любого слова(слов).
  Один шаблон покрывает бесконечно много значений (каналы, поисковые запросы).
- **Claude fallback**: если ни один шаблон не подошёл, фраза уходит в
  `claude -p` с инструкцией вернуть структурированное действие или короткий
  голосовой ответ. Медленнее (~3–8 c), поэтому только для нераспознанных фраз.

## Действия v1

1. **Запуск игр/программ** — `launch_app`: через Steam-URL (`steam://...`),
   ярлык или путь к `.exe`. Список — в `apps.yaml`.
2. **Сайты + поиск** — `open_url`: открытие ссылки в браузере по умолчанию
   (напр. `twitch.tv/{канал}`, `youtube.com/results?search_query={запрос}`).
   **Расширение Chrome не требуется** — достаточно открыть правильный URL.
3. **Системные команды** — громкость, пауза/музыка, блокировка/выключение ПК,
   скриншот (`pycaw`, системные вызовы).
4. **Свободный вопрос к Claude** — фраза уходит в `claude -p`, ответ
   озвучивается Speaker'ом.

## Конфигурация (примеры)

```yaml
# apps.yaml
дота:    steam://rungameid/570
апекс:   steam://rungameid/1172470
дискорд: C:/Users/Admin/AppData/Local/Discord/Update.exe

# commands.yaml  (* = любое слово(слова))
"открой канал * на твиче":  open_url  twitch.tv/{0}
"найди на ютубе *":         open_url  youtube.com/results?search_query={0}
"открой ютуб":              open_url  youtube.com
"запусти *":                launch_app {0}
"сделай громче":            system volume_up

# settings.yaml
wake_word: "джони"
picovoice_access_key: "<ключ>"
response_mode: voice        # voice | beep | off
whisper_model: medium       # small | medium | large
whisper_device: cuda
```

## Обработка ошибок

- Не расслышал / пусто → сигнал «не понял», ничего не запускает.
- Программа не найдена в `apps.yaml` → «Не знаю такой программы».
- `claude -p` недоступен/долго → «Не смог разобрать команду».
- Ни один шаблон не совпал и Claude отключён → «Не понял команду».
- Никаких действий без явной команды после слова-активатора.

## Технологии

- **Язык:** Python (лучшая экосистема голосовых библиотек под Windows).
- Всё офлайн и бесплатно, кроме опционального `claude -p` (Pro-подписка).
- **Запуск:** сначала окно-консоль (видно, что происходит и логи);
  позже — сворачивание в системный трей.

## Тестирование

- **Router и шаблоны** — тестируются текстом (без микрофона): подаём строку,
  проверяем выбранное действие и извлечённые параметры.
- **Actions** — на моках: проверяем, что вызвана нужная команда с нужными
  аргументами, без реального запуска игр/сайтов.
- **ClaudeBrain** — мок вызова `claude -p`, проверка парсинга ответа.
- Голосовые модули (Listener/Recognizer/Speaker) — ручная проверка + тонкая
  подстройка на этапе интеграции.
