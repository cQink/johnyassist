## Add social media ingestion and analysis (feeds, key users, style analysis)

Цель: Собирать данные из социальных сетей и анализировать участников и стиль коммуникаций.

Критерии успеха:
- Есть connector для одного канала (например, Telegram) собирающий поток сообщений.
- Наличие аналитики: частотный анализ участников, тональность, темы.

Шаги:
1. Спроектировать коннектор API для каждой платформы (rate limits, auth).
2. Реализовать хранилище потоков и индекс для поиска.
3. Добавить NLP pipeline (topic modeling, sentiment, named-entity recognition).

Зависимости: NLP библиотеки (spaCy, transformers)

Приватность/безопасность: соблюдение политик платформ и получение согласия

Оценка: 5-10 дней
