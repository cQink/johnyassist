Цель: Подключить локальный переводчик для UX и быстрой локализации ответов.

Критерии успеха:
- Перевод текста локально с UI-гарнитурой.

Шаги:
1. Изучить проект Translator и требования.
2. Интегрировать как опцию в UI ассистента для перевода текста/аудио.

Зависимости: языковые модели (напр., Marian), упаковка desktop

Приватность/безопасность: локальная обработка предпочтительна

Оценка: 2-4 дней
