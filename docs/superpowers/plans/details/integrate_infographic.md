## Integrate antvis/Infographic (infographic generation)

Цель: Использовать Infographic для генерации визуализаций из данных и автоматических отчётов.

Критерии успеха:
- Генерация PNG/SVG инфографики из JSON-данных.

Шаги:
1. Ознакомиться с API Infographic и примерами.
2. Сделать адаптер, принимающий данные и возвращающий изображение.
3. Интегрировать в workflow отчётов.

Зависимости: Node.js

Приватность/безопасность: данные должны быть анонимизированы при необходимости

Оценка: 2-4 дней
