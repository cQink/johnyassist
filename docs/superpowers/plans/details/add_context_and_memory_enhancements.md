## Add context and memory enhancements

Цель: Улучшить сохранение и извлечение контекстных данных и фактов о пользователе и сессиях.

Критерии успеха:
- Существует персистентная память (диалог + факты) с API получения/обновления.
- Контекст подставляется в промпты автоматически и ограничен по объёму.

Шаги:
1. Описать модель памяти (short-term, long-term, facts).
2. Выбрать хранилище (SQLite / JSON / vector DB) и реализовать адаптер.
3. Добавить API для CRUD памяти и тесты.
4. Интегрировать с модулями генерации промптов.

Зависимости: возможно `faiss`/`weaviate` для векторного поиска

Приватность/безопасность: шифрование long-term данных, GDPR-совместимость

Оценка: 4-7 дней
