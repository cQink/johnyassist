## Integrate social platforms connectors (X/Twitter, Telegram, Discord, Facebook, VK)

Цель: Создать адаптеры для популярных соцплатформ для сбора и отправки сообщений.

Критерии успеха:
- Поддержка чтения потока и отправки сообщений в минимум одной платформе.
- Поддержка webhooks/long polling где применимо.

Шаги:
1. Приоритизировать платформы по доступности API и потребностям.
2. Реализовать адаптер с абстракцией (fetch, send, auth).
3. Закрыть edge-cases: rate-limits, reconnection.

Зависимости: API keys, SDK платформ

Приватность/безопасность: хранение токенов в `secrets.yaml` и шифрование

Оценка: 5-14 дней
