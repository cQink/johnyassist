## Add external AI prompt proxy support in editors

Цель: Позволить ассистенту проксировать промпты из редакторов в выбранные модели/сервисы и возвращать изменения.

Критерии успеха:
- Есть безопасный прокси endpoint, принимающий контекст файла и prompt.
- Результат может быть автоматически или вручную применён к файлу.

Шаги:
1. Спроектировать API для проксирования promtps (auth, size limits).
2. Реализовать сервер-прокси и CLI/extension-клиент для VS Code.
3. Добавить логирование и версионирование изменений.

Зависимости: web framework (FastAPI), auth

Приватность/безопасность: проверка и маскирование секретов в промптах

Оценка: 3-6 дней
