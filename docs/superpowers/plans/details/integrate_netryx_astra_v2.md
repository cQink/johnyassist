## Integrate Netryx-Astra-V2 OSINT connector

Цель: Подключить OSINT pipeline для агрегирования данных из публичных источников.

Критерии успеха:
- Установлен и протестирован Netryx-Astra-V2 для одного сценария (например, сбор профилей).

Шаги:
1. Ознакомиться с репозиторием и требуемыми зависимостями.
2. Настроить локальное окружение и сделать примерный crawl.
3. Интегрировать результаты в единый индекс для поиска.

Зависимости: внешние ресурсы, возможно docker

Приватность/безопасность: не собирать приватные/закрытые данные

Оценка: 3-7 дней
