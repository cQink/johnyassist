## Add auto-reply engine (draft, review, send) with moderation & safety

Цель: Построить pipeline для черновой генерации ответов, их ревью и отправки с политиками безопасности.

Критерии успеха:
- Генерация черновика ответа с указанием вероятности токсичности и рекомендацией.
- Возможность ручного/автоматического отправления с логом и отменой.

Шаги:
1. Определить workflow: ingest -> draft -> review -> send.
2. Интегрировать safety-модуль (toxicity, PII detection).
3. Реализовать UI/CLI для ревью и отправки.

Зависимости: модуль модерации, API платформ

Приватность/безопасность: mandatory human-in-the-loop для чувствительного контента

Оценка: 5-12 дней
