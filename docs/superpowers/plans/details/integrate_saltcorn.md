## Integrate Saltcorn no-code builder

Цель: Подключить Saltcorn для быстрого создания внутренних инструментов и дашбордов.

Критерии успеха:
- Создан рабочий пример приложения (dashboards) на Saltcorn.

Шаги:
1. Развернуть Saltcorn и изучить плагины.
2. Создать шаблон приложения для отображения аналитики.

Зависимости: Node.js, DB

Приватность/безопасность: контролировать доступ к данным

Оценка: 2-4 дней
