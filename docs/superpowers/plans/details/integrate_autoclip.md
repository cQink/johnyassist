## Integrate zhouxiaoka/autoclip (video clipping/highlight)

Цель: Добавить автоматическую генерацию клипов и хайлайтов из видео.

Критерии успеха:
- Можно загрузить видео и получить клипы по событиям/сценам.

Шаги:
1. Изучить `autoclip` и его зависимости.
2. Запустить локальный пример и проверить pipeline выделения хайлайтов.
3. Создать адаптер для очередей задач (Celery) для асинхронной обработки.

Зависимости: ffmpeg, pytorch

Приватность/безопасность: обнаружение и маскирование лиц при необходимости

Оценка: 3-7 дней
