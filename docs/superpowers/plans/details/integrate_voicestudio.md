## Integrate VoiceStudio (debpalash/VoiceStudio)

Цель: Подключить VoiceStudio как локальную/облачную платформу для прототипирования голосовых моделей.

Критерии успеха:
- Можно генерировать голосовые сэмплы и тестировать pipeline.

Шаги:
1. Клонировать репозиторий VoiceStudio и изучить зависимости.
2. Запустить локально и проверить генерацию голосов.
3. Сделать адаптер для вызова из `johnny`.

Зависимости: TTS libs, python env

Приватность/безопасность: не загружать приватные аудио без согласия

Оценка: 2-5 дней
