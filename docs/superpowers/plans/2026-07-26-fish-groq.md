# Голос Джарвиса (fish.audio) и быстрые ответы (Groq) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Джони отвечает голосом Джарвиса за 1–2 секунды вместо 4–7, не занимая видеопамять.

**Architecture:** Синтез становится цепочкой fish → edge → pyttsx3, где каждое звено подхватывает за упавшим предыдущим. Короткие служебные фразы кешируются на диск и играются без сети. Логика «мозга» (промпт, разбор ответа, защита от разрушительных команд) отделяется от способа вызова модели, после чего к ней подключаются два провайдера: Groq по HTTP и нынешний `claude -p`.

**Tech Stack:** Python 3.14, Windows, `requests`, fish.audio API (`s2.1-pro-free`), Groq API (`llama-3.3-70b-versatile`), pytest.

**Спека:** `docs/superpowers/specs/2026-07-26-fish-groq-design.md`

## Global Constraints

- Комментарии, docstring'и и текст, который Джони произносит, — **по-русски**. Комментарий объясняет ПОЧЕМУ, а не пересказывает код.
- Браузерный `User-Agent` в каждом HTTP-запросе к fish и Groq **обязателен**: Cloudflare отдаёт `error code: 1010` клиенту без него. Заголовок помечен комментарием — не удалять как «лишний».
- Ключи API живут только в `config/secrets.yaml` (в `.gitignore`). **Ни один ключ не должен попасть ни в код, ни в тесты, ни в коммит.**
- Ни один тест не ходит в сеть. HTTP подменяется через `monkeypatch`.
- Любая ошибка сети/провайдера — не исключение наружу, а спуск на ступень ниже по цепочке. Ошибка каждого вида логируется один раз за запуск (`warn_once`), дальше — в `debug`.
- Модель fish: `s2.1-pro-free`. Модель Groq: `llama-3.3-70b-versatile`. `fish_model_id` голоса Джарвиса: `81d5531b63c8459790f5a625ed5de915`.
- Таймаут запроса к fish и к Groq — 10 секунд.
- Кеш: только тексты **не длиннее 40 символов**, не больше **100 файлов** в `models/tts-cache/`, запись атомарная.
- Защита от разрушительных команд (`is_unsafe_action`, отсутствие таких команд в промпте) сохраняется дословно — это исправление уже найденного бага, не переписывать.
- Запуск тестов: `.venv/Scripts/python.exe -m pytest tests/ -q` из корня `D:\assistent`. Все 163 существующих теста должны оставаться зелёными после каждой задачи.

```python
import logging

import requests

logger = logging.getLogger(__name__)

# И fish.audio, и Groq стоят за Cloudflare, который отдаёт «error code: 1010»
# любому клиенту без браузерного User-Agent. Заголовок ОБЯЗАТЕЛЕН — на этом
# уже потеряли час, не удалять как лишний.
USER_AGENT = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
    "(KHTML, like Gecko) Chrome/140.0 Safari/537.36"
)

# Ключи ошибок, о которых уже предупреждали в этом запуске.
_warned: set[str] = set()


def warn_once(key: str, message: str) -> None:
    """Первую ошибку каждого вида — в WARNING, повторы — в DEBUG.

    Пропавший интернет иначе заливает johnny.log одной и той же строкой на
    каждую произнесённую фразу; на это уже наступали в цикле прослушивания.
    """
    if key in _warned:
        logger.debug("%s", message)
        return
    _warned.add(key)
    logger.warning("%s", message)


def post(url: str, headers: dict, payload: dict, timeout: float):
    """POST с JSON-телом и браузерным User-Agent. Возвращает Response как есть:
    fish отдаёт mp3 (.content), Groq — JSON (.json())."""
    return requests.post(
        url, headers={**headers, "User-Agent": USER_AGENT}, json=payload, timeout=timeout
    )
```

```python
def _fish(monkeypatch, tmp_path, response=None, fallback=None, boom=False):
    """Собрать say() с подменёнными сетью и проигрыванием. Возвращает (say, events)."""
```

```python
import hashlib
import os
import random
import tempfile
from pathlib import Path

from . import sounds
from .http_client import post, warn_once

_URL = "https://api.fish.audio/v1/tts"
_MODEL = "s2.1-pro-free"      # бесплатная модель клонирования голоса
_TIMEOUT = 10.0

# Кешируем только служебные реплики Джони («Не понял команду», «Не расслышал»):
# они звучат сотнями раз и в 40 символов укладываются все. Ответы модели длиннее
# и дословно не повторяются — кешировать их значит копить мусор.
_MAX_CACHED_CHARS = 40
_MAX_CACHE_FILES = 100
_CACHE_DIR = Path(__file__).resolve().parent.parent / "models" / "tts-cache"


def synthesize(text: str, api_key: str, model_id: str, timeout: float = _TIMEOUT) -> bytes:
    """mp3 с голосом Джарвиса. Бросает исключение при любой неудаче."""
    response = post(
        _URL,
        {"Authorization": f"Bearer {api_key}", "model": _MODEL},
        {"text": text, "reference_id": model_id, "format": "mp3"},
        timeout,
    )
    if response.status_code != 200:
        raise RuntimeError(f"fish HTTP {response.status_code}: {response.text[:120]}")
    return response.content


def _cache_path(cache_dir, text: str) -> Path:
    return Path(cache_dir) / f"{hashlib.sha1(text.encode('utf-8')).hexdigest()}.mp3"


def _store(path: Path, data: bytes) -> None:
    """Запись через временный файл: оборванный ответ сети не должен остаться
    в кеше под правильным именем и звучать обрезком до конца времён."""
    path.parent.mkdir(parents=True, exist_ok=True)
    temp = path.with_suffix(".part")
    temp.write_bytes(data)
    os.replace(temp, path)


def _trim(cache_dir, limit: int = _MAX_CACHE_FILES) -> None:
    """Оставить не больше limit файлов, удаляя самые старые."""
    files = sorted(Path(cache_dir).glob("*.mp3"), key=lambda p: p.stat().st_mtime)
    for old in files[: max(0, len(files) - limit)]:
        old.unlink(missing_ok=True)


def make_fish_tts(api_key: str, model_id: str, fallback, cache_dir=_CACHE_DIR, play=sounds.play_file):
    """say() голосом Джарвиса; при любой неудаче — fallback (edge-Дмитрий)."""

    def say(text: str) -> None:
        if not text:
            return
        cached = _cache_path(cache_dir, text) if len(text) <= _MAX_CACHED_CHARS else None
        if cached is not None and cached.exists():
            try:
                play(str(cached))
                return
            except Exception:
                warn_once("fish-cache", "Файл из кеша не проигрался — синтезирую заново")

        try:
            data = synthesize(text, api_key, model_id)
        except Exception as error:
            warn_once("fish", f"fish недоступен ({error}) — озвучиваю запасным голосом")
            fallback(text)
            return

        path = cached or Path(tempfile.gettempdir()) / (
            f"johnny_fish_{os.getpid()}_{random.randint(0, 1_000_000)}.mp3"
        )
        _store(path, data)
        if cached is not None:
            _trim(cache_dir)
        try:
            play(str(path))
        finally:
            if cached is None:
                path.unlink(missing_ok=True)

    return say
```

```python
import os
import shutil
import subprocess


def _find_claude() -> str:
    """Полный путь к claude. Под pythonw (трей) голое имя не резолвится в
    claude.cmd (CreateProcess не знает PATHEXT) и вызов молча падал —
    поэтому ищем реальный файл: which (учитывает PATHEXT), затем npm-папку.
    """
    found = shutil.which("claude") or shutil.which("claude.cmd")
    if found:
        return found
    guess = os.path.join(os.environ.get("APPDATA", ""), "npm", "claude.cmd")
    return guess if os.path.isfile(guess) else "claude"


_CLAUDE = _find_claude()


def run(prompt: str) -> str:
    """Ответ claude -p. Пустая строка = недоступен, зовущий пробует следующего."""
    try:
        # Промпт передаём через stdin, а не argv: claude.cmd — batch-обёртка,
        # и многострочный текст с кавычками/скобками в аргументе калечится.
        result = subprocess.run(
            [_CLAUDE, "-p"],
            input=prompt,
            capture_output=True,
            text=True,
            encoding="utf-8",
            timeout=120,
        )
        return result.stdout
    except Exception:
        # claude недоступен/таймаут — без трейсбека в логе на каждую фразу.
        return ""
```

```python
import json
import re
from dataclasses import dataclass, field

from . import brain_claude
from .router import RoutedAction, is_unsafe_action, route

_PROMPT = """Ты — голосовой ассистент Джони на компьютере с Windows.
Текст ниже пришёл от распознавания речи и МОГ БЫТЬ ИСКОВЕРКАН.

Пользователь сказал: "{text}"

Вот команды, которые Джони умеет ({count} шт.):
{commands}

1) Если это исковерканная КОМАНДА из списка — ответь ТОЛЬКО JSON с точной
фразой из списка (звёздочку замени тем, что сказал пользователь):
{{"command": "громкость 5"}}

2) Если это команда управления компьютером, которой в списке НЕТ (открыть
произвольный сайт, запустить программу) — ответь ТОЛЬКО JSON:
{{"action": "<open_url|launch_app|system>", "argument": "<url | имя программы | volume_up/volume_down/mute/lock>", "reply": "<короткая фраза для озвучки>"}}

3) Если это ВОПРОС, просьба рассказать, пошутить или просто поговорить —
ответь живой человеческой речью по-русски, 1–3 коротких предложения, БЕЗ JSON
(твой ответ будет прочитан вслух)."""


def _extract_json(raw: str) -> dict | None:
    match = re.search(r"\{.*\}", raw, re.DOTALL)
    if not match:
        return None
    try:
        return json.loads(match.group(0))
    except json.JSONDecodeError:
        return None


@dataclass
class BrainResult:
    routed: RoutedAction | None
    reply: str | None
    # Кто ответил — для истории и лога. В сравнении не участвует, иначе
    # тесты пришлось бы завязывать на имя провайдера.
    provider: str = field(default="", compare=False)


def interpret(text: str, commands=None, providers=None) -> BrainResult | None:
    """Спросить модель. providers — список (имя, функция prompt->текст),
    перебираются по порядку до первого непустого ответа."""
    commands = commands or []
    providers = providers or [("claude", brain_claude.run)]
    # Разрушительные команды (выключение/перезагрузка/сон) не показываем
    # модели вовсе — их нельзя предлагать угадывать даже как «исправление».
    safe_commands = [rule for rule in commands if not is_unsafe_action(rule.action, rule.template)]
    listing = "\n".join(f"- {rule.pattern}" for rule in safe_commands)
    prompt = _PROMPT.format(text=text, count=len(safe_commands), commands=listing)

    raw, name = "", ""
    for name, provider in providers:
        raw = provider(prompt)
        if raw and raw.strip():
            break
    if not raw or not raw.strip():
        return None  # пусто у всех = моделей нет на связи

    data = _extract_json(raw)
    if data is not None:
        # Режим коррекции: модель узнала ослышку. Выполняет обычный route() —
        # так модель не может изобрести действие или собрать кривой аргумент.
        corrected = data.get("command")
        if corrected:
            routed = route(corrected, commands)
            if routed is not None and is_unsafe_action(routed.action, routed.argument):
                # «Исправление» указывает на разрушительное действие — выполнять
                # нельзя, даже если модель сама это предложила.
                routed = None
            return BrainResult(routed=routed, reply=None, provider=name)
        action = data.get("action")
        reply = data.get("reply") or None
        if action in ("open_url", "launch_app", "system"):
            argument = data.get("argument", "")
            if is_unsafe_action(action, argument):
                return BrainResult(routed=None, reply=None, provider=name)
            routed = RoutedAction(action=action, argument=argument, via=name)
            return BrainResult(routed=routed, reply=reply, provider=name)
        if action == "answer":
            return BrainResult(routed=None, reply=reply, provider=name)
        # Валидный JSON, но ни одной из ожидаемых форм ("command"/action) —
        # озвучивать сырой JSON нельзя, app.py скажет «Не понял команду».
        return BrainResult(routed=None, reply=None, provider=name)

    # Не JSON — значит это обычный разговорный ответ, озвучиваем его как есть.
    return BrainResult(routed=None, reply=raw.strip(), provider=name)
```

```python
from .http_client import post, warn_once

_URL = "https://api.groq.com/openai/v1/chat/completions"
_TIMEOUT = 10.0


def make_provider(api_key: str, model: str):
    """Функция prompt -> текст ответа. Пустая строка = не смог, пусть отвечает
    следующий провайдер (claude -p)."""

    def run(prompt: str) -> str:
        try:
            response = post(
                _URL,
                {"Authorization": f"Bearer {api_key}"},
                {
                    "model": model,
                    "messages": [{"role": "user", "content": prompt}],
                    # Ответ либо строгий JSON, либо короткая реплика вслух —
                    # фантазия тут не нужна.
                    "temperature": 0.3,
                },
                _TIMEOUT,
            )
            if response.status_code != 200:
                raise RuntimeError(f"Groq HTTP {response.status_code}: {response.text[:120]}")
            return response.json()["choices"][0]["message"]["content"]
        except Exception as error:
            warn_once("groq", f"Groq недоступен ({error}) — спрашиваю claude")
            return ""

    return run
```
